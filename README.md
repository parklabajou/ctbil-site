# CTBiL 홈페이지 관리 메모

아주대 분자과학기술학과 박현지 교수님 연구실(Cell Therapy & Bioinformatics Lab) 홈페이지 소스예요. 코딩을 몰라도 논문, 뉴스, 사진, 팀원 정보 정도는 직접 고칠 수 있게 만들어 놨으니, 필요할 때 이 문서를 보면서 하나씩 따라 하시면 됩니다.

페이지는 GitHub Pages로 올려 두고, 구글 사이트(ctbi.ajou.ac.kr)에서 페이지마다 하나씩 임베드해서 보여주는 구조예요. 그래서 GitHub에서 파일만 고치면 구글 사이트는 따로 손댈 필요가 없습니다.

## 파일 구성

- `index.html`: 대문. 연구실 소개(한글·영문), 사진 한 장, 모집 안내, 연락처가 있어요.
- `team.html`: 구성원. 교수님, 현재 구성원, 졸업생 순서로 나와요.
- `research.html`: 연구 주제 4개와 연구 사진.
- `publications.html`: 논문 목록. 연도 버튼과 검색창이 있어요.
- `patents.html`: 특허 목록. 등록/출원으로 나뉘고 검색할 수 있어요.
- `news.html`: 뉴스. 연도별로 묶여서 접었다 펼 수 있고, 태그별로 걸러볼 수 있어요.
- `gallery.html`: 갤러리. 사진을 누르면 크게 보여요.
- `contact.html`: 연락처, 지도, 채용 안내.
- `설정가이드.html`: GitHub Pages와 구글 사이트 연결 방법을 그림으로 설명한 문서.
- `images/`: 사진 폴더 (아래 "사진 올리기" 참고).

디자인은 흰 배경에 아주대 블루(`#0072CE`)와 골드(`#B08D3C`)를 포인트로 썼고, 폰트는 Space Grotesk와 Inter예요. 페이지 맨 위 제목 영역은 모든 페이지가 같은 모양이고, 오른쪽 사진이 들어가는 자리는 아래 파일을 `images/` 에 올리면 채워져요. 파일이 없으면 사진 없이 글만 깔끔하게 보이니까 급하게 안 올려도 괜찮습니다.

## 고치는 기본 방법

각 페이지 파일에는 "여기만 수정하세요"라고 적힌 주석 구간이 있어요. 그 안의 글자만 바꾸면 되고, 디자인 코드는 건드릴 일이 없습니다.

새 항목을 추가할 땐 기존 블록(`<article> ... </article>` 같은 것) 하나를 통째로 복사해서 맨 위에 붙여넣고 글자만 바꾸세요. 따옴표나 쉼표는 신경 안 써도 되고, 칸이 비어 있어도 페이지가 깨지진 않아요.

## 논문 추가 (`publications.html`)

`pub-data` 아래에 이 블록을 복사해서 맨 위에 붙여넣고 내용만 바꿔요.

```html
<article year="2026" tags="Co-first">
  <p class="abbr">Nat. Comm.</p>
  <p class="authors">홍길동*, ... <b>Park HJ&dagger;</b></p>
  <p class="title">여기에 논문 제목을 적습니다</p>
  <p class="journal">Nature Communications 2026, 17:1234</p>
  <p class="link">https://doi.org/논문주소</p>
</article>
```

- `year`: 연도예요. 아직 심사 중이면 `year="Submitted"` 라고 쓰세요. Under review 묶음으로 들어가고, 처음엔 접혀 있다가 Show 버튼을 누르면 펼쳐져요.
- `tags`, `abbr`: 지금은 화면에 안 나와요. 비워도 되고 그대로 둬도 상관없습니다.
- `authors`: 저자예요. 우리 랩 사람은 `<b>Park HJ</b>` 처럼 감싸면 진하게 나오고, 공동 1저자는 이름 뒤에 `*`, 교신저자는 `&dagger;` 를 붙여요.
- `title`: 논문 제목.
- `journal`: 저널명, 권, 호, 페이지.
- `link`: 논문이나 DOI 주소예요. 넣으면 제목에 링크가 걸리고 아래에 DOI가 보여요. 없으면 비워두세요.

번호는 자동으로 붙어요. 발행된 논문에 오래된 순으로 1번부터 매기니까 가장 최근 논문이 제일 큰 번호가 되고, 심사 중인 논문에는 번호가 안 붙습니다.

연도 순서는 자동으로 정렬되는데, 같은 연도 안에서는 적어 둔 순서 그대로 보여요. 그래서 새 논문은 꼭 맨 위에 붙여넣어 주세요.

지금은 2012~2022년 논문이 연도별로 나뉘지 않고 한 묶음으로 보이게 해 뒀어요. 기준은 논문 목록 바로 위에 있는 이 한 줄이에요.

```html
<div id="pub-settings" hidden merge-until="2022"></div>
```

기준 연도를 바꾸려면 숫자만 고치면 돼요(예를 들어 `2023` 으로 하면 2012~2023이 한 묶음). 연도별로 다 따로 보고 싶으면 `merge-until=""` 처럼 비워두세요. 묶음 이름(2012–2022)은 실제로 들어 있는 논문 연도를 보고 알아서 정해져요.

필터 상태가 주소에 저장돼서 바로가기 링크도 만들 수 있어요.

- 특정 연도: `publications.html?year=2025`
- 심사 중만: `publications.html?year=review`
- 묶어 둔 옛 논문만: `publications.html?year=older`

## 뉴스 추가 (`news.html`)

`news-data` 아래에 복사해서 맨 위에 붙여넣어요.

```html
<article date="2026.08.17" type="award" label="Award">
  <p class="txt">여기에 소식 본문을 적습니다. 강조는 &lt;b&gt;이름&lt;/b&gt; 처럼, 링크는 &lt;a href="주소"&gt;Link&lt;/a&gt; 로.</p>
  <p class="imgs">images/사진1.jpg
images/사진2.jpg</p>
</article>
```

- `date`: 날짜 (예: `2026.08.17`)
- `type`: 태그 색깔이에요. `award`(수상, 금색), `talk`(발표, 파랑), `career`(진로, 초록), `grant`(연구비·장학, 보라), `event`(행사, 청록), `paper`(논문, 남색) 중에서 고르세요.
- `label`: 태그에 보일 글자 (예: `Award`, `Career`, `Scholarship`)
- `txt`: 본문. 문장이 여러 개여도 돼요.
- `imgs`: 사진 경로예요. 여러 장이면 줄을 바꾸거나 띄어서 쓰고, 없으면 비워두세요. 장수에 맞게 칸이 알아서 나뉘고, 누르면 크게 보여요. 파일이 없는 사진은 자동으로 사라져요.

소식은 `date` 앞 네 자리를 보고 연도별로 자동으로 묶여요. 처음엔 가장 최근 연도만 펼쳐져 있고, 다른 연도는 제목 줄이나 Show 버튼을 누르면 펼쳐져요. 위쪽의 Expand all / Collapse all 로 한 번에 열고 닫을 수도 있어요. 태그 버튼으로 거르면 결과가 짧으니 그땐 모든 연도가 펼쳐져서 보여요.

같은 연도 안에서는 적힌 순서 그대로 보이니까, 새 소식은 꼭 맨 위에 붙여넣어 주세요.

사진은 지금 적혀 있는 경로(`images/news/...`, `images/...`)에 실제 파일이 있어야 보여요. 파일명이 조금이라도 다르면 그 칸은 그냥 사라지니, 안 보이면 GitHub 의 `images` 폴더에서 파일명을 한 번 맞춰보세요.

## 대문 (`index.html`)

위에서부터 제목, 한글 소개, 영문 소개, 사진 한 장, 모집 안내, 연락처 순서예요. 각 문장은 그냥 글자만 바꾸면 되고, 줄을 바꾸고 싶은 자리에 `<br>` 을 넣으면 돼요(좁은 화면에선 줄바꿈이 무시되고 자연스럽게 흐릅니다).

사진은 `images/hero.jpg` 를 올리면 들어가고, 파일이 없으면 사진 자리가 통째로 사라져요. 가로로 긴 사진(16:9 정도)이 잘 어울려요.

연락처의 전화번호는 비워 뒀어요. 넣고 싶으면 `index.html` 의 Contact 부분에 주석으로 적어 둔 Phone 두 줄을 꺼내서 번호를 적으세요.

구글 사이트에 나눠서 넣을 수도 있어요. 주소 뒤에 `?show=intro` 를 붙이면 제목과 소개만, `?show=join` 을 붙이면 모집 안내와 연락처만 보여요. 그래서 사진을 GitHub 에 올리는 대신 구글 사이트 것으로 쓰고 싶으면, 이렇게 구성하면 돼요.

1. `index.html?show=intro` 를 임베드
2. 그 아래에 구글 사이트의 삽입 → 이미지 캐러셀(또는 이미지)로 사진을 넣기
3. 그 아래에 `index.html?show=join` 을 임베드

사진 교체를 구글 사이트 편집기에서 클릭 몇 번으로 끝낼 수 있어서, 사진이 자주 바뀐다면 이 방법이 편해요.

## 연구 페이지 (`research.html`)

연구 주제는 `<section class="area">` 하나가 주제 하나예요. 안의 영어 문장만 바꾸면 되고, 주제를 늘리고 싶으면 section을 통째로 복사해서 붙인 다음 Area 번호와 사진 파일명 번호를 같이 바꿔주세요.

주제마다 연구 사진을 최대 3장까지 넣을 수 있어요. `images/research/` 폴더를 만들고 `area1-1.jpg`, `area1-2.jpg`, `area1-3.jpg` 처럼 올리면 되고(주제 번호-사진 번호), 파일이 없는 칸은 자동으로 비워져요. 아직 이 폴더에 사진을 올리기 전이라 지금은 사진 없이 글만 보이는 게 정상이에요. 사진은 잘리지 않고 통째로 보이고, 누르면 확대돼요. 4장 이상 넣고 싶으면 사진 줄을 복사해서 번호만 바꾸세요. 다른 파일명을 쓰고 싶으면 `<a class="fig" href="...">` 줄의 경로 두 군데를 같이 바꾸면 돼요.

## 팀원 추가 (`team.html`)

현재 구성원은 `<div class="m"> ... </div>` 블록 하나를 복사해서 붙이고 아래 칸을 바꾸면 돼요.

- `<h3>`: 이름
- `class="role"`: 직책 (예: `Ph.D. Student`, `Undergraduate Intern`)
- `class="deg"`: 학교, 소속, 기간 (예: `UCLA`, `Since 2026.07`)
- `class="topic"`: 연구 주제 (예: `Vascular organoid engineering`)
- `class="email"`: 이메일이에요. 카드에 그대로 보이니까, 안 보이게 하려면 이 줄을 지우세요.
- `class="bio"`: 카드를 눌렀을 때 뜨는 팝업의 소개글
- 사진: `data-photo="images/members/파일명.jpg"` 에 경로를 넣어요. 비워두거나 파일이 없으면 `data-initial="HP"` 의 이니셜이 대신 나와요. 팀원 사진은 `images/members/` 폴더에 올리세요.

마스코트는 `class="m mascot"` 로 쓰면 금색 아바타가 돼요.

졸업생은 `<div class="al"> ... </div>` 블록을 복사해요. `class="when"` 에는 `Master's student · 2024–2026` 처럼 "직급 · 기간" 형태로 써 주세요. 가운데 점 앞의 직급이 같은 사람끼리 자동으로 묶여서 Postdoc, Master's student 같은 제목 아래에 나와요. 현재 구성원 수와 졸업생 수도 제목 옆에 자동으로 붙어요.

## 특허 추가 (`patents.html`)

`pat-data` 아래에서 `<article>` 블록을 복사해서 붙이고, 아래 항목을 맞춰주세요.

- `status`: `reg`(등록) 또는 `pend`(출원, 심사 중)
- `country`: 국가나 구분 (예: `Korea`, `PCT`)
- `title`, `inventors`, `no`(번호), `statusText`(화면에 보일 상태 글자)

등록과 출원은 화면에서 알아서 나뉘고, 번호도 자동으로 붙어요.

## 갤러리 사진 추가 (`gallery.html`)

1. `images/` 폴더에 사진을 올려요 (바로 아래 "사진 올리기" 참고).
2. 갤러리 사진 목록에 아래처럼 한 줄 추가해요.

```js
{ src:"images/lab_dinner.jpg", cap:"Lab dinner, 2026" },
```

`src` 는 사진 주소, `cap` 은 사진 아래 설명이에요. 지금 들어 있는 `ph(...)` 는 미리보기용 임시 그림이라 실제 사진 주소로 바꾸면 돼요.

## 사진 올리기

1. GitHub 저장소에서 `images` 폴더를 눌러요. 폴더가 아직 없으면 Add file → Create new file 에서 이름을 `images/.gitkeep` 으로 만들면 폴더가 생겨요.
2. Add file → Upload files 로 사진을 끌어다 놓고 Commit changes 를 눌러요.
3. 올린 사진 주소는 `images/파일명.jpg` 형태예요. 파일명은 영어와 숫자로 하는 게 안전해요.

## 수정한 내용 게시하기

GitHub 웹에서 바로 고칠 수 있어요.

1. 저장소에서 고칠 파일(예: `publications.html`)을 눌러요.
2. 오른쪽 위 연필(Edit) 아이콘을 눌러요.
3. 내용을 고쳐요.
4. 아래쪽 초록색 Commit changes 버튼을 눌러요.
5. 1~2분쯤 지나면 사이트에 반영돼요. 구글 사이트는 건드릴 필요 없어요.

큰 수정은 파일을 컴퓨터에 내려받아서 더블클릭해 브라우저에서 먼저 확인한 뒤 올리면 안전해요. 사진은 `images` 폴더도 같이 내려받아 같은 위치에 둬야 보여요.

## 실수했을 때

- 파일 화면 오른쪽 위의 History 에서 이전 버전을 눌러 내용을 복사해 되돌릴 수 있어요.
- 아니면 커밋 목록에서 잘못된 커밋 옆의 `...` → Revert 를 눌러도 돼요.

변경 기록이 다 남아 있어서 언제든 되돌릴 수 있으니 너무 걱정하지 마세요.

## 구글 사이트에 연결하기 (처음 한 번만)

그림으로 된 자세한 설명은 `설정가이드.html` 을 열어 보세요. 요약하면 이래요.

1. 이 저장소의 Settings → Pages 에서 Branch 를 `main` / `(root)` 로 두고 Save 를 눌러요.
2. 그러면 `https://아이디.github.io/저장소이름/` 주소가 생겨요.
3. 구글 사이트 편집기에서 페이지마다 삽입 → URL 기준(Embed by URL)으로 해당 페이지 주소를 넣어요. 대문은 `.../index.html`, 논문은 `.../publications.html`, 뉴스는 `.../news.html`, 팀은 `.../team.html` 같은 식이에요.
4. 전체 페이지(Whole page)로 넣고, 상자 높이를 넉넉하게 늘려 주세요.

한 가지 알아 둘 점이 있어요. 페이지마다 따로 임베드하는 구조라서, 연구 페이지 아래의 "Get in touch →" 같은 링크를 누르면 구글 사이트 메뉴가 아니라 임베드된 상자 안에서 다음 페이지가 열려요. 마음에 걸리면 그 링크의 `href` 를 구글 사이트의 해당 페이지 주소로 바꾸고 `target="_top"` 을 붙여 주세요. 대문의 "Contact Prof. Park →" 버튼은 메일 쓰기 창을 여는 거라 괜찮아요.
