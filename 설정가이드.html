Setup Guide

CTBiL 웹사이트 설정 가이드

GitHub Pages에 페이지를 올리고, 구글 사이트에 임베드하는 방법입니다. 순서대로 따라 하시면 됩니다. 코딩 지식은 필요 없어요.

📁받으신 파일

index.html대문(홈) — 히어로·연구소개·최근 논문/뉴스
publications.html논문 — 연도별 목록, 데이터만 수정해 갱신
news.html뉴스 — 타임라인 피드, 태그 색상 구분
gallery.html갤러리 — 사진 그리드 + 클릭 확대
💡 논문·뉴스·갤러리는 각 파일 안의 데이터 목록(▼▼▼ 표시 구간)만 고치면 내용이 바뀝니다. 디자인 코드는 건드릴 필요 없어요.

1GitHub에 올리기

GitHub Pages는 무료로 웹페이지를 호스팅해주는 기능입니다.

  1. github.com에서 계정을 만듭니다(무료). 이미 있으면 로그인.
  2. 오른쪽 위 + → New repository 클릭.
  3. Repository name에 ctbil-site 처럼 입력하고, Public 선택 → Create repository.
  4. 새 저장소 화면에서 uploading an existing file 링크 클릭.
  5. 받으신 index.html · publications.html · news.html · gallery.html 4개를 드래그해서 올리고 Commit changes.
🖼️ 갤러리에 실제 사진을 넣으려면: 저장소에 images 폴더를 만들어 사진을 올린 뒤, gallery.html의 목록에서 src를 images/파일명.jpg로 바꾸면 됩니다.

2GitHub Pages 켜기

  1. 저장소 상단 Settings → 왼쪽 메뉴 Pages.
  2. Branch를 main, 폴더는 / (root)로 두고 Save.
  3. 1~2분 뒤 새로고침하면 주소가 나옵니다:
    https://아이디.github.io/ctbil-site/
  4. 각 페이지 주소는 뒤에 파일명을 붙인 형태입니다:
    페이지주소 예시
    대문.../ctbil-site/index.html
    논문.../ctbil-site/publications.html
    뉴스.../ctbil-site/news.html
    갤러리.../ctbil-site/gallery.html
✅ 각 주소를 브라우저에서 먼저 열어 제대로 보이는지 확인한 뒤 다음 단계로 가세요.

3구글 사이트에 임베드

구글 사이트는 주소와 상단 메뉴 등 뼈대를 맡고, 각 페이지 내용은 위 GitHub 주소를 불러옵니다.

  1. 구글 사이트 편집기에서 원하는 페이지(예: 논문)로 이동.
  2. 오른쪽 삽입(Insert) 패널에서 삽입(Embed) 클릭.
  3. URL 기준(By URL) 탭에 해당 페이지의 GitHub 주소를 붙여넣기 → 삽입.
  4. 미리보기가 뜨면 전체 페이지(Whole page) 선택.
  5. 삽입된 상자의 모서리를 드래그해 높이를 넉넉히 늘려주세요(내용이 잘리지 않게).
  6. 이 방식으로 각 페이지(대문·논문·뉴스·갤러리)에 해당 주소를 하나씩 넣습니다.
📐 높이 팁: 임베드는 높이가 고정이라 내용이 길면 잘릴 수 있어요. 상자를 충분히 크게 늘리거나, 페이지 하나에 임베드 하나만 배치하는 걸 권장합니다. 폭은 가로 전체(full width)로 두면 가장 예쁩니다.
🔗 상단 메뉴 구성은 구글 사이트에서 합니다: Team·Research·Contact 등 기존 페이지는 그대로 두고, 같은 아주대 블루 계열로 테마 색만 맞추면 통일감이 좋아집니다.

4앞으로 업데이트하는 법

논문·뉴스·사진 추가는 GitHub에서 데이터 한 줄만 고치면 됩니다. 구글 사이트는 건드릴 필요 없어요.

논문 추가

  1. GitHub에서 publications.html 열고 연필(Edit) 아이콘 클릭.
  2. const PUBLICATIONS = [ 바로 아래에 기존 { ... } 한 줄을 복사해 붙이고, 연도·제목·저자·저널만 수정.
  3. 아래 초록 버튼 Commit changes → 1~2분 뒤 자동 반영.

뉴스 추가

news.html의 const NEWS = [ 아래에 항목을 추가. 태그 종류는 award·talk·career·grant·recruit 중 선택.

사진 추가

images 폴더에 사진 올리고, gallery.html의 PHOTOS 목록에 { src:"images/파일명.jpg", cap:"설명" } 추가.

🔧 나중에 원하시면 논문·뉴스를 구글 시트에서 관리하도록 연결해, 시트에 한 줄 추가하면 사이트가 갱신되게 확장할 수도 있어요. 필요하면 말씀해 주세요.
